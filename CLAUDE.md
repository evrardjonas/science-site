# Instructions pour Claude Code

Lire `AGENTS.md` et `ARCHITECTURE.md` avant toute modification.

Pour chaque tâche :

1. conserver l’architecture statique et la compatibilité GitHub Pages ;
2. limiter les changements au besoin demandé ;
3. réutiliser les composants et le design system existants ;
4. expliquer toute nouvelle dépendance ;
5. exécuter `npm run check` et `npm run build` ;
6. travailler sur une branche et proposer une pull request pour toute modification importante.
